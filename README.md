Bangalore House Price Predictor
📌 Project Synopsis
A machine learning website called Bangalore House Price Predictor makes predictions about Bangalore real estate prices based on:
Total Square Feet
The quantity of restrooms
The quantity of BHK
Where
Real Bangalore, India housing data is used to train the model, and a Python backend with a contemporary HTML/CSS frontend is used for deployment.

**
Features**

✅ Preprocessing and data cleaning

✅ Removal of outliers (price per square foot and BHK logic)

✅ Feature engineering (one-hot encoding, BHK extraction)

✅ GridSearchCV model selection

Assessment of cross-validation

✅ Flask The Rest API backend

✅ Contemporary glassmorphism user interface

✅ Validating input and managing errors

✅ Prediction API based on JSON

✅ Pickle was used for model export.

**Tech Stack**
